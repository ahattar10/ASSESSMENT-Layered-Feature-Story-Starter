Project Overview

  • Project title: Move More, Feel Better
  • Project type: Public-information project
  • Topic: How exercise improves health
  • Audience: Students and community members
  • Purpose: Explain how regular movement can improve physical and mental health.

Reading Order

  1. Site header and navigation
  2. Hero eyebrow and main title
  3. Introduction
  4. Main feature image
  5. Physical-health section
  6. Mental well-being section
  7. Secondary image
  8. Practical advice section
  9. Conclusion
  10. Call to action
  11. Sources and documentation
  12. Footer

Layout Plan

  • CSS Grid is used for the hero and article regions.
  • Flexbox is used for navigation and metadata.
  • Paragraphs remain in normal document flow.
  • No essential content is positioned manually.
  • There are no fixed-height containers for essential text.

Shape Plan

  • Rounded corners are used on images, cards, panels, and buttons.
  • clip-path creates a decorative angled edge on the call-to-action panel.
  • shape-outside: circle(50%) allows text to wrap around a circular image.
  • If these effects do not work, the content remains readable in normal blocks.

Layer Plan

  • --layer-base: 0
  • --layer-content: 1
  • --layer-decoration: 2
  • --layer-anchored: 3
  • --layer-focus: 4

Essential content stays in normal document flow. Decorative layers do not block links or controls, and keyboard focus remains visible.

Element Content purpose Normal-flow baseline Chosen technique and why Containing block / stacking context Fallback or disengagement Required test
Hero badge Displays the decorative message "Anchored detail." The badge could appear as a normal label above or below the hero content. Use position: absolute to anchor the badge over the hero without creating a content column. The .feature-header section is the containing block because it uses position: relative. The badge uses the anchored layer token. On small screens, reduce or reposition the badge so it does not cover the title, image, links, or important text. Test at 320px and 1280px, with a long title, keyboard focus, and pointer activation.
Sticky story guide Provides persistent links to the story sections so readers can jump around while scrolling. The guide appears as a normal <aside> beside or after the article. Use position: sticky so the guide remains visible while the reader moves through the story. The <main> element is the containing layout context because it uses display: grid. The guide remains bounded within the grid track it occupies. Below the 52rem breakpoint, the guide is not sticky and appears in normal document flow. Test at 320px and 1280px, at the page and section boundaries, and with doubled paragraphs.
Overlapping quotation Emphasizes that an exercise routine should fit realistically into a person’s life. The quotation appears as a normal blockquote at the end of the "Start With a Realistic Change" section. Use controlled absolute positioning to let the quote overlap the surrounding paragraph's white space without covering essential paragraphs or links. The .image-frame is the containing block because it uses position: relative. At small widths, remove absolute positioning and return the quotation to normal document flow. Test at 320px, 768px, and 1280px, with doubled paragraphs and keyboard focus.
Rounded images and cards Groups related visual content and creates a consistent editorial appearance. Images, cards, notes, and panels remain ordinary block elements. Use border-radius as a visual enhancement only. These elements remain in normal flow and do not need a new stacking context. If the border radius is removed, the content remains complete as rectangular blocks. Test at 320px, 768px, 1280px, 200% zoom, and with CSS disabled.
Call-to-action panel Encourages readers to choose one small, manageable movement goal. The heading, paragraph, and link appear in a normal content panel. Use clip-path to create a decorative angled panel edge. The panel remains in normal article flow. Its essential content is not dependent on clipping. If clip-path is disabled, the panel remains a readable rounded rectangle. Disable clip-path and test the panel, link, keyboard focus, 320px layout, and CSS-disabled reading order.
Editorial shape wrap Allows introductory text to flow around a decorative circular image. The image appears as a normal block before or beside the paragraph. Use float, shape-outside: circle(50%), and shape-margin for an editorial text wrap. The shape participates in the article’s normal flow and does not create an arbitrary positional column. If shape wrapping is unsupported or disabled, the image becomes a normal block and the text remains readable. Disable shape-outside and test at 320px, 200% zoom, with doubled paragraphs, and with CSS disabled.
Layer token system Keeps overlaps predictable and prevents arbitrary high z-index values. Elements appear in source order without assigned layer values. Use the documented tokens --layer-base, --layer-content, --layer-decoration, --layer-anchored, and --layer-focus. Only elements requiring layering receive a token. Decorative elements use pointer-events: none. Removing the layer values leaves the semantic source order intact. Focus outlines remain visible above decorative elements. Inspect the hero, badge, decoration, sticky note, image frame, quotation, and focused links in browser developer tools.
